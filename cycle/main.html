A loop is a repeated sequence of actions or set of commands that are executed over and over again until a specified ending condition is met.

Typically we either look for the first match, filter out garbage, or limit the number of attempts. (Ищем первое совпадние/фильтруем мусор/ограничиваем кол-во попыток).

This is a great way to improve the skill of managing the flow of execution. (навык управления потоком выполнения)
